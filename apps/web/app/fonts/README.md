# Fontes locais

Nunito Sans (400–700) e Playfair Display (400–600), versões variáveis WOFF2, subconjunto latino que inclui os caracteres de português. Obtidas da distribuição oficial Google Fonts em 18/10/2026. As licenças SIL Open Font License estão neste diretório.

Fontes: https://fonts.google.com/specimen/Nunito+Sans e https://fonts.google.com/specimen/Playfair+Display.

Carregadas com `next/font/local`, preload e `display: swap`, com fallback. O build e o navegador não dependem de chamadas ao Google para carregar tipografia.
